PREGUNTAS FRECUENTES

Preguntas frecuentes sobre el sistema.

¿Qué incluye el sistema de gestión para talleres?

Incluye presupuestos y cotizaciones, órdenes de trabajo, repuestos ingresados, compras, facturación y boletas, y la administración del personal, todo conectado a una misma base de datos.

¿Necesito internet para usarlo?

Para mantener la información sincronizada entre el computador, el celular Android y la web, se requiere conexión a internet.

¿Puedo usarlo desde el celular?

Sí. Además de la versión para computador y el acceso web, cuenta con una aplicación para Android para registrar trabajos y consultar información directamente en el taller.

¿Varios usuarios pueden trabajar a la vez?

Sí. Puede crear distintos usuarios con permisos específicos para consultar y administrar la información según las funciones asignadas.
